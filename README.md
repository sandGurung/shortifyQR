# Shortify & QR Studio 🚀

**Free URL Shortener with Custom QR Code & Frame Generator** — An all-in-one, modern Next.js application for link shortening, click analytics, and custom QR code design with no sign-up required.

🌐 **Live Demo**: [https://shortifyqr.vercel.app](https://shortifyqr.vercel.app)

---

## ✨ Key Features

### 🔗 1. Free URL Shortener with Auto QR (Same Page)
- **Instant Short Links**: Shorten long, messy URLs into clean short links with custom aliases (slugs).
- **Auto QR Code Generation**: Instantly generates a downloadable QR code image **directly on the same page** upon clicking *Shorten Link Now*.
- **Expiration Rules**: Set links to expire in 24 hours, 7 days, 30 days, or Never.
- **Click-to-Copy & Test**: 1-click link copying and quick redirect testing.

### 🎨 2. Custom Frame QR Code Generator & Studio
- **Input Any Link or Text**: Generate QR codes for website URLs, plain text, WiFi credentials (SSID/password), VCards, Email templates, or WhatsApp messages.
- **Custom Module Patterns**: Choose from Rounded, Extra Soft, Circular Dots, Classy Sharp, Classy Smooth, or Classic Square.
- **Corner Eye Shapes**: Extra Rounded, Square, or Circle Eye frames and center dots.
- **Vibrant Gradients & Colors**: Linear and Radial color gradients with dual color stop pickers, plus solid and transparent background fill options.
- **Brand Logo Upload**: Upload custom logo images or choose from preset icons (GitHub, X, Website, Instagram, LinkedIn, WiFi, Email).
- **Decorative CTA Frames**: Add top & bottom call-to-action badge banners (e.g., "SCAN ME", "VISIT WEBSITE", "CONNECT WIFI").
- **Design Presets**: Pre-built themes ("Cyber Neon", "Minimal Dark", "Sunset Glow", "Emerald Luxury", "Vibrant Indigo").
- **High-Resolution Exports**: Download as PNG, SVG (vector), WEBP, or printable layout.

### 👁️ 3. Live Website Visitor Counter & Click Analytics
- **Website Visitor Badge**: Live visitor count badge displayed on the top Navbar and Footer.
- **Link Analytics Dashboard**: Track total click counts, visitor device breakdown (Mobile vs Desktop), referral sources, and 7-day visitor timelines.

## 🛠️ Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/sandGurung/shortifyQR.git
cd shortifyQR

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev

# 4. Open in browser
http://localhost:3000
```

---

## 🚀 Deploying to Vercel for Free

1. Push your repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import your repository and click **Deploy**. Vercel will automatically detect Next.js App Router and build it!
